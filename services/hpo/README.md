# atlas-hpo

ATLAS Phase 8 hyperparameter optimization engine (v0.8.0).

## Capabilities

- Optuna-first hyperparameter optimization for approved training jobs
- Random, grid, and TPE search modes behind a shared interface
- Trial history, best trial selection, and immutable study artifacts
- HITL approve / reject / export flow
- MinIO-backed optimization artifacts and JSON-first visualizations
